## シミュレーションで求めた値と設定値

次の数値は文献から取ったものではありません。動画を説明するために決めた設定値と、pd\_anim のシミュレーションで求めた値です。実際の検出器の値として引用しないでください。

| 値 | 種類 | 内容 |
| --- | --- | --- |
| 層の厚さ・速度・電離率 (電子 0.12、正孔 0.004 / フレーム) | 設定値 | 見せ方のために規格化した値。実際の寸法や時間ではない |
| APD の平均利得 22.5、F = 2.71 | シミュレーション | 10 万回。実効 k = 0.057 で McIntyre の式は F ≈ 3.1 |
| 平均利得 70 の APD | 指定の設計値 | 電離率を 0.1388 にして平均を約 70 に合わせた。20 万回で 〈M〉 = 69.8、F = 4.86 |
| PMT 7 段、各段のゲイン 4 | 指定の設計値 | 二次電子数はポアソン分布と仮定。平均 4⁷ = 16384 |
| PMT の F = 1.334 | シミュレーション | 20 万回。理論値 1 + 1/4 + … + 1/4⁶ = 1.333 \[12\] |
| HPD の打ち込みゲイン 200 | 指定の設計値 | ポアソン分布と仮定。実機の値 (数千) \[13\] \[14\] より小さい |
| HPD の F = 1.025 | シミュレーション | 20 万回。式 F = F1 + (F2 − 1)/G1 の値 1.0247 と一致 |

PMT と HPD の F は、pd\_anim とは別に Python (numpy) でも計算して確かめました。PMT は F = 1.3333 (40 万回)、HPD は F = 1.0248 (10 万回、2 段目は平均 70・F = 4.94 の分布で代用) で、どちらも一致しています。

F = F1 + (F2 − 1)/G1 は、「平均 G1 個の電子がそれぞれ独立に平均 G2 倍に増える」という確率変数の和の分散から導いた式です。

```latex
\mathrm{Var}(T) = \langle G_1\rangle\,\sigma_2^2 + \sigma_1^2\,\langle G_2\rangle^2 \;\Rightarrow\; F = 1 + \frac{\mathrm{Var}(T)}{\langle T\rangle^2} = F_1 + \frac{F_2 - 1}{\langle G_1\rangle}
```

## 出典と照合して直した点
