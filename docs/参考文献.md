## シミュレーションで求めた値と設定値

次の数値は文献から取ったものではありません。動画を説明するために決めた設定値と、pd_anim のシミュレーションで求めた値です。実際の検出器の値として引用しないでください。

| 値 | 種類 | 内容 |
| --- | --- | --- |
| 層の厚さ・速度・電離率 (電子 0.12、正孔 0.004 / フレーム) | 設定値 | 見せ方のために規格化した値。電離率は増倍層の中で一定 (実際は電界に強く依存) |
| APD の平均利得 22.5、F = 2.71 | シミュレーション | 10 万回。実効 k = 0.057 で McIntyre の式は F ≈ 3.1 |
| 平均利得 70 の APD | 指定の設計値 | 電離率 0.1388。10 万回で 〈M〉 = 70.7、F = 4.94 |
| PMT 7 段、各段 4 | 指定の設計値 | 二次電子数はポアソン分布と仮定。平均 4⁷ = 16384 |
| PMT の F = 1.334 | シミュレーション | 2 万回。理論値 1 + 1/4 + … + 1/4⁶ = 1.333 [11] |
| HPD の打ち込み 200、APD 70 | 指定の設計値 | 打ち込みはポアソン分布と仮定。実機は打ち込み約 1500、APD 約 80 [17] |
| HPD の F = 1.024 | シミュレーション | 2 万回。式 F = F1 + (F2 − 1)/G1 の値 1.025 と一致 [11] [12] |

PMT と HPD の F は、pd_anim とは別に Python (numpy) でも計算して確かめました (PMT 1.3333、HPD 1.0248)。

F = F1 + (F2 − 1)/G1 は、「平均 G1 個の電子がそれぞれ独立に平均 G2 倍に増える」という確率変数の和の分散から導いた式です。

```latex
\mathrm{Var}(T) = \langle G_1\rangle\,\sigma_2^2 + \sigma_1^2\,\langle G_2\rangle^2 \;\Rightarrow\; F = 1 + \frac{\mathrm{Var}(T)}{\langle T\rangle^2} = F_1 + \frac{F_2 - 1}{\langle G_1\rangle}
```
